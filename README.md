# Customer Behavior Data Analytics Project

##  Overview
This project analyzes customer purchase behavior using a retail dataset to uncover 
insights around revenue, discounts, product performance, shipping preferences, and 
customer loyalty. The workflow covers the complete data analytics pipeline — from 
loading and cleaning data in Python, performing exploratory data analysis (EDA), 
running SQL queries for deeper business insights, building an interactive Power BI 
dashboard, and presenting findings through a report and presentation.

The goal of this project is to answer real-world business questions that companies 
use to guide marketing, pricing, and customer retention strategies.

##  Dataset
The dataset contains customer-level purchase records with details such as:
- Customer demographics (gender, age)
- Purchase details (item purchased, category, purchase amount)
- Customer engagement (review rating, discount applied, subscription status)
- Shipping type and previous purchase history

##  Tools Used
- **Python** – Data loading, cleaning, and exploratory data analysis (Pandas, NumPy)
- **SQL (PostgreSQL / MySQL / SQL Server)** – Querying and business insight extraction
- **Power BI** – Interactive dashboard and data visualization
- **Gamma** – Presentation (PPT) creation
- **Jupyter Notebook** – Development environment for Python analysis

##  Steps Followed
1. **Data Loading** – Imported the raw dataset into Python using Pandas.
2. **Data Cleaning** – Handled missing values, fixed data types, removed duplicates, 
   and standardized column formats.
3. **Exploratory Data Analysis (EDA)** – Explored trends, distributions, and 
   relationships between variables using Python.
4. **Database Setup** – Loaded the cleaned dataset into a SQL database 
   (PostgreSQL/MySQL/SQL Server) using SQLAlchemy.
5. **SQL Analysis** – Wrote SQL queries using aggregations, CASE statements, CTEs, 
   and window functions to answer key business questions.
6. **Dashboard Creation** – Built an interactive Power BI dashboard to visualize 
   key metrics and trends.
7. **Reporting** – Summarized findings into a business-friendly report.
8. **Presentation** – Created a PPT using Gamma to present insights in a clear, 
   visual format.

##  Dashboard
The Power BI dashboard highlights:
- Revenue breakdown by gender and age group
- Discount usage patterns and their impact on spending
- Top-performing products and categories
- Subscription vs. non-subscription customer behavior
- Customer segmentation (New, Returning, Loyal)

##  Key Business Questions Answered
1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above average
3. Top 5 products with the highest average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Spending comparison between subscribers and non-subscribers
6. Top 5 products with the highest percentage of discounted purchases
7. Customer segmentation into New, Returning, and Loyal customers
8. Top 3 most purchased products within each category
9. Relationship between repeat buyers and subscription likelihood
10. Revenue contribution by age group
